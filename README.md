# DE-Stopwatch

Športové stopky
Funkcie -
4 buttony - Start, Stop, Reset, Lap
Ukladacia kapacita 8 lap časov, zobrazenie pomocou 4 switchov, pri 9. a každom nasledujúcom lap čase začne prepisovať vśetky predchádzajúce lap časy počínajúc prvým
24 hodinovy format zobrazujuci hodiny, minuty, sekundy, stotiny

Rozdelenie uloh -
Breza - Programovanie funkcii, video
Blumaier - Top level design, prezentaciu, plagat
Bednařík - Vymyslenie funkcii programu, blokové schéma, debugging
